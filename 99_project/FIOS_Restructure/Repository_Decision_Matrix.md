# FIOS Repository Decision Matrix

## Decision Types

- ✅ KEEP
- 🔄 MERGE
- 📦 MOVE
- 🗄 ARCHIVE
- ❌ DELETE
- 🚧 FUTURE

---

| Folder / File | Purpose | Decision | Reason | Target |
|---------------|---------|----------|--------|--------|

---

## Rules

### KEEP
Core architecture or actively used.

### MERGE
Duplicate responsibility.

### MOVE
Wrong location.

### ARCHIVE
Useful history but not runtime.

### DELETE
Unused, duplicate, or obsolete.

### FUTURE
Reserved for upcoming roadmap.

---

## Final Objective

Every folder and file in FIOS must have exactly one justified decision.

Nothing remains without purpose.
